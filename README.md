# PRODEXA - automatizando cadastros.

Prodexa é uma ferramenta para automatizar cadastros de produtos, com coleta de
fotos, descrição e apoio de inteligência artificial.

## Como executar

1. Instale o Python 3.11 ou mais recente.
2. Dê duplo clique em `Executar_PRODEXA.bat`.

O iniciador instala automaticamente as bibliotecas necessárias e abre a
interface. Para usar os recursos de IA, informe a chave da API na aba de IA.
